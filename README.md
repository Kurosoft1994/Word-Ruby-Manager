# RubyManager - Word VBA ルビ一括管理＆学習システム (Reverse Processing Edition)

Microsoft Word文書内のルビ（フリガナ）を一括追加・削除・補正するVBA標準モジュールです。
表記揺れの防止、レイアウト保持、および学習者レベル別の表示制御を自動化します。

---

## 🌟 主な機能と特徴

1. **6つの操作モード**
   - 【追加】すべてに振る / ページ内で最初に出た単語のみ / 段落内で最初に出た単語のみ
   - 【消去】すべて消去 / ページの最初のルビを残して重複消去 / 段落の最初のルビを残して重複消去
2. **学習レベル別スキップ機能**
   - **入門**: 全漢字 ＋ カタカナへの「ひらがナルビ」
   - **初級**: JLPT N5レベル基本漢字（約100字）を自動スキップ
   - **中級**: JLPT N5+N4レベル漢字（約300字）を自動スキップ
   - **カスタム**: 辞書登録単語のみ対象
3. **1文字漢字の対話型選択＆履歴学習**
   - 文脈で読みが変わる単漢字に対し、文書上の位置を画面スクロール＆ハイライトした状態で選択可能。選択結果は自動記憶されます。
4. **末尾からの逆順移動・処理（Step -1構造）**
   - ルビ付与に伴う文字位置（Rangeオフセット）のズレを防ぐため、**必ず文書の末尾（最終ページ/最終段落）から先頭に向かって逆順で移動・処理**を行います。
5. **レイアウト崩れ防止・自動補正**
   - 行間の自動固定、テキストボックス文字あふれ調整、ページ境界維持オプションを実装。
6. **設定・辞書の永続化 (`ruby_config.ini`)**
   - 前回実行時の各種設定や学習した単語辞書を UTF-8 設定ファイルに自動保存。

---

## 🚀 使い方・セットアップ

1. Wordで本マクロを適用したい文書を開きます。
2. `Alt + F11` を押して VBA Editor を起動します。
3. メニューの `[挿入] -> [標準モジュール]` を選択し、`RubyManager.bas` のコードを貼り付けます。
4. Word画面に戻り、`Alt + F8` を押して `RubyManagerSystem_RubyFirst` を実行します。
5. ダイアログの指示に従ってモードやレベルを選択してください。（入力画面で `?` または `H` を入力すると詳細ヘルプが表示されます）

## 🧠 AIと人間の協調開発プロセス（思考過程と設計思想）

本プロジェクトは、生成AI（LLM）によるコード生成と、人間による仕様定義・構造分析（Human-in-the-Loop）の組み合わせによって開発されました。

### 1. 課題発生と解析アプローチの限界
初期開発において、「正方向（文頭から文末）にルビを付与すると全体の文字数が増加し、後続の文字位置やページ先頭位置がリアルタイムに変動する」という課題が発生しました。

AI側の初期提案は、**「各ページの初期位置を関数等で事前解析・データ化し、ルビ振りによって位置が変動しても元の位置を追跡・補正しながら正方向に処理する」**というアプローチでした。しかし、位置追跡ロジックが複雑化した結果、データの一致精度が上がらず、不具合を解消できない状態が継続しました。

### 2. 処理構造の見直し（事前解析の廃止と逆順処理）
この課題に対し、事前解析および補正処理によるアプローチを中止する判断を行いました。

代わりのアプローチとして、**「文書の末尾（最終ページ・文末）から先頭に向かって逆順（Step -1）にルビ処理を行う」**方式を採用しました。末尾から処理を進めることで、ルビ追加による位置変化（Rangeオフセットの増減）は常に処理済みの後方領域にのみ影響し、これから処理する前方の未処理領域の位置情報には影響を与えないためです。

### 3. モジュールおよび関数の再構成
指示に基づき、既存の解析関数を廃棄し、文末からの逆順移動を行うアルゴリズムへ再構成しました。結果として処理ロジックが簡素化され、文字位置のズレが生じない設計が実現しました。

### 【要件定義】

#### 1. モード選択（全6モード）
実行時に入力ダイアログ（InputBox）を表示し、以下のいずれかを選択できるようにしてください。
- 1: 【ルビ追加】すべてに振る（全指定）
- 2: 【ルビ追加】ページの最初に出た単語だけに振る（ページ単位）
- 3: 【ルビ追加】段落の最初に出た単語だけに振る（段落単位）
- 4: 【ルビ消去】すべて消去する
- 5: 【ルビ消去】ページの最初のルビを残して重複を削除する（ページ単位）
- 6: 【ルビ消去】段落の最初のルビを残して重複を削除する（段落単位）

#### 2. 対象レベルと自動スキップ
ルビ追加時、学習レベルを選択可能にしてください。
- 1【入門】: 全漢字 ＋ カタカナ（ひらがなルビ）
- 2【初級】: 基本漢字（JLPT N5レベル約100字）を自動スキップ
- 3【中級】: 応用漢字（JLPT N5+N4レベル約300字）を自動スキップ
- 4【カスタム】: 辞書登録単語のみ

#### 3. 1文字漢字の対話型選択＆履歴学習
- 熟語ではない単漢字の場合、「音読み優先」「訓読み固定」「対話選択」を選べるようにすること。
- 「対話選択」の場合、文章中の該当文字を画面スクロールでハイライトし、選択肢（過去履歴・推測読み）の番号選択または直接入力を受け付けること。
- 選択・入力した結果は自動的にカスタム辞書へ学習・保存され、次回以降最優先で適用されること。

#### 4. 設定および辞書の永続化（ruby_config.ini）
- アクティブ文書と同じフォルダに ruby_config.ini（UTF-8）を自動生成・読み込み・保存すること。
- 前回実行時の選択モード、ルビ比率、レイアウト設定、学習した単語辞書をすべて保存し、ダイアログの初期値として再現すること。

#### 5. レイアウト崩れ防止オプション
- 0: 補正なし / 1: 行間固定 / 2: テキストボックス文字あふれ調整 / 3: ページ境界維持 / 4: 全適用
- 複数指定（例: 12）にも対応すること。

#### 6. UI/UXとコード設計ルール
- Alt+F8のマクロ一覧にはメインプロシージャ（例: RubyManagerSystem_RubyFirst）のみが表示されるよう、その他のサブルーチン・関数はすべて Private で宣言すること。
- すべてのInputBoxダイアログで「?」または「H」が入力された場合、その画面専用の【コンテキスト詳細ヘルプ】（MsgBox）を表示して再入力させる仕組み（InputBoxWithHelp）を実装すること。
- Excelオブジェクト（GetPhonetic）を使用した正確な振り仮名取得を行なうこと。

#### 7. 処理順序（末尾からの逆順移動・処理） 【重要】
- ルビ付与・削除による文章長や改ページ位置のズレ（Rangeオフセット変化）を防ぐため、事前解析や補正処理に頼らず、必ず文書の末尾（最終ページ／最終段落）から先頭ページに向かって逆順（Step -1）で移動・処理するプログラム構造にすること。
