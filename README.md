# Word Ruby Manager (v1.0.0)

Microsoft Word文書内の漢字・カタカナに対して、直感的なルールでルビ（フリガナ）を一括追加・消去するためのVBAマクロです。  
教育現場、日本語教材の作成、出版物の組版作業などの効率化を目的として開発されています。

---

## ✨ 主な特徴

* **🔄 一貫性のある直感的な操作モード**
  * 「全部振る / 取る」
  * 「ページの最初だけ振る / ページの頭を残して取る（ページ単位）」
  * 「段落の最初だけ振る / 段落の頭を残して取る（段落単位）」
* **🎓 学習者のレベルに応じた自動 ルビ制限**
  * **入門**：全漢字 ＋ カタカナ
  * **初級**：JLPT N5レベル（基本100字）を自動スキップ
  * **中級**：JLPT N5+N4レベル（約300字）を自動スキップ
  * **カスタム**：登録した特定用語・熟語のみ
* **📖 1文字漢字の読み選択＆履歴学習**
  * 熟語ではない単漢字（例：「角」「表」など）の音訓選択・直接入力をサポート。選択結果は自動的に学習・保存されます。
* **⚙️ レイアウト崩れ防止オプション**
  * ルビ付与に伴う行間広がりやテキストボックスの文字あふれ、ページ境界のズレを自動補正。
* **💾 設定・辞書の自動保存**
  * 文書と同じフォルダにある `ruby_config.ini` へ設定とカスタム辞書を保存し、次回以降に引き継ぎます。

## 🚀 使い方（インストール＆実行）

### 1. コードの導入
1. Wordで対象の文書を開きます。
2. `Alt + F11` を押して VBE（VBAエディタ）を開きます。
3. メニューの **[挿入] ➔ [標準モジュール]** をクリックします。
4. `RubyManager.bas` のコード全文を貼り付けます。
5. VBE画面を閉じます。

### 2. マクロの実行
1. Word画面で `Alt + F8` を押します。
2. マクロ一覧から **`RubyManagerSystem_RubyFirst`** を選択して「実行」をクリックします。
3. 画面の対話形式ダイアログ（InputBox）に従って設定番号を入力します。

> **💡 ヒント**  
> 設定ダイアログで `?` または `H` を入力して「OK」を押すと、各設定の詳しいヘルプが表示されます。

## 📝 開発の振り返りとAIプロンプト (Development Summary & AI Prompt)

### 1. 今回の作業の振り返り (Project Summary)

本Word VBAマクロ（RubyManager）は、実務や教育現場での利便性を追求し、単なる自動処理にとどまらない品質と操作性を実現しました。

#### 🌟 主な機能と工夫したポイント
1. **直感的で一貫性のある操作モード**
   - 追加・消去ともに「全指定」「ページ単位」「段落単位」の統一されたルールで設計し、迷わず操作可能。
2. **学習者レベルに応じたルビ制御**
   - 入門向け「カタカナへのひらがナルビ」から、基本漢字（JLPT N5/N4レベル等）の自動スキップ機能まで幅広く対応。
3. **1文字漢字の対話型選択＆履歴学習**
   - 文脈で読みが変わる単漢字（例:「角」「表」）に対し、対話形式で音訓を選択・入力可能。選択結果は自動記憶されます。
4. **設定およびカスタム辞書の自動保存 (`ruby_config.ini`)**
   - UTF-8対応の `.ini` ファイル入出力処理により、前回設定や学習した単語辞書を自動保存・復元。
5. **優れたUI/UXとコードの美しさ**
   - **コンテキストヘルプ**: 入力画面で `?` や `H` を入力すると詳細ヘルプを表示。
   - **Alt+F8 メニューの整理**: エントリポイント以外を `Private` 化し、標準モジュールをクリーンに保ちます。
6. **レイアウト崩れ補正処理**
   - ルビ付与に伴う行間の広がり、テキストボックスの文字あふれ、ページ境界のズレを抑える自動補正機能を完備。

### 【要件定義】

#### 1. モード選択（全6モード）
実行時に入力ダイアログ（InputBox）を表示し、以下のいずれかを選択できるようにしてください。
- 1: 【ルビ追加】すべてに振る（全指定）
- 2: 【ルビ追加】ページの最初に出た単語だけに振る（ページ単位）
- 3: 【ルビ追加】段落の最初に出た単語だけに振る（段落単位）
- 4: 【ルビ消去】すべて消去する
- 5: 【ルビ消去】ページの最初のルビを残して重複を削除する（ページ単位）
- 6: 【ルビ消去】段落の最初のルビを残して重複を削除する（段落単位）

#### 2. 対象レベルと自動スキップ
ルビ追加時、学習レベルを選択可能にしてください。
- 1【入門】: 全漢字 ＋ カタカナ（ひらがなルビ）
- 2【初級】: 基本漢字（JLPT N5レベル約100字）を自動スキップ
- 3【中級】: 応用漢字（JLPT N5+N4レベル約300字）を自動スキップ
- 4【カスタム】: 辞書登録単語のみ

#### 3. 1文字漢字の対話型選択＆履歴学習
- 熟語ではない単漢字の場合、「音読み優先」「訓読み固定」「対話選択」を選べるようにすること。
- 「対話選択」の場合、文章中の該当文字を画面スクロールでハイライトし、選択肢（過去履歴・推測読み）の番号選択または直接入力を受け付けること。
- 選択・入力した結果は自動的にカスタム辞書へ学習・保存され、次回以降最優先で適用されること。

#### 4. 設定および辞書の永続化（ruby_config.ini）
- アクティブ文書と同じフォルダに ruby_config.ini（UTF-8）を自動生成・読み込み・保存すること。
- 前回実行時の選択モード、ルビ比率、レイアウト設定、学習した単語辞書をすべて保存し、ダイアログの初期値として再現すること。

#### 5. レイアウト崩れ防止オプション
- 0: 補正なし / 1: 行間固定 / 2: テキストボックス文字あふれ調整 / 3: ページ境界維持 / 4: 全適用
- 複数指定（例: 12）にも対応すること。

#### 6. UI/UXとコード設計ルール
- Alt+F8のマクロ一覧にはメインプロシージャ（例: RubyManagerSystem_RubyFirst）のみが表示されるよう、その他のサブルーチン・関数はすべて Private で宣言すること。
- すべてのInputBoxダイアログで「?」または「H」が入力された場合、その画面専用の【コンテキスト詳細ヘルプ】（MsgBox）を表示して再入力させる仕組み（InputBoxWithHelp）を実装すること。
- Excelオブジェクト（GetPhonetic）を使用した正確な振り仮名取得を行なうこと。
